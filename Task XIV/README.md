# Task XIV - BI and AI Data Preparation

## Objective
Prepare analytical SQL outputs for dashboards and downstream AI/ML experiments using the existing e-commerce database.

## Requirements covered
- Window functions: RANK() and ROW_NUMBER()
- Customer segmentation by spending
- Category and product performance analytics
- Feature extraction for an AI-ready customer dataset
- NULL-safe metrics and ordered analytical outputs

## SQL
Run `task_14.sql` in MySQL 8.0+. Results can be exported from MySQL Workbench as CSV for analysis in Python, Tableau, or another analytics tool. The script does not claim to train an AI model; it prepares structured features for later model development.
