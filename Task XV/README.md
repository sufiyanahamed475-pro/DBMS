## Objective
Integrate the earlier InventoryDB tasks into a coherent e-commerce intelligence workflow: schema, sample data, queries, reusable views, automation, transactions, access control, indexes, and analytical reporting.

## Database modules
- Catalog and inventory: `Category`, `Product`
- Customer and orders: `Customer`, `Orders`, `Order_Details`
- Payments: `Payment`
- Feedback: `Review`, `Rating`

## Files
